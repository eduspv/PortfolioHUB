## Título do projeto

PortfolioHUB — Portfólio e versionamento com Git e GitHub Pages

## Descrição (seção Projetos)

Repositório de portfólio criado no Bootcamp I do curso de Ciência da Computação (UniCEUB). Reúne meus projetos acadêmicos e pessoais, entre eles uma plataforma de saúde mental em Go e React, e documenta o uso de Git com versão inicial (v1.0.0), commits no padrão Conventional Commits e melhorias posteriores. O site foi publicado no GitHub Pages com HTML, CSS e JavaScript, com layout responsivo e foco em acessibilidade.

## Competências sugeridas

Git, GitHub, GitHub Pages, HTML5, CSS3, JavaScript, Documentação técnica, Versionamento de código.

## Onde inserir

1. Abra https://www.linkedin.com/in/eduardo-s-p-vidal/
2. **Adicionar seção do perfil → Recomendado → Adicionar projeto**.
3. Preencha nome, descrição e competências acima, e cole o link do site (ou do repositório) em "Adicionar mídia/link".
4. Opcional: em **Destaques**, adicione o link do site e do vídeo do YouTube.
5. Tire uma captura de tela do projeto publicado para anexar ao PDF.
