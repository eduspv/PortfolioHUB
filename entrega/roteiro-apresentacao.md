# Roteiro da apresentação (≈ 5 minutos)

Fale com naturalidade; os textos são sugestões. Deixe abertas, em abas: perfil do GitHub, repositório PortfolioHUB, página de commits, página de tags, site publicado e perfil do LinkedIn.

## 0:00–0:40 · Introdução
**Mostrar:** site publicado, topo da página.
**Falar:** "Olá, eu sou o Eduardo Serra Pierre Vidal, aluno de Ciência da Computação no UniCEUB. Neste vídeo apresento a entrega intermediária do Bootcamp I: um repositório no GitHub, o PortfolioHUB, que reúne meus projetos, usa versionamento com Git e está publicado no GitHub Pages."

## 0:40–1:30 · GitHub
**Mostrar:** github.com/eduspv, depois o repositório PortfolioHUB e a árvore de pastas.
**Falar:** "Este é o meu perfil, com meus repositórios públicos. No PortfolioHUB, o index.html, o css e o js formam o site. As pastas projetos-academicos e projetos-pessoais documentam cada projeto, documentacao tem planejamento, versionamento e LinkedIn, e entrega guarda este roteiro. O README explica tudo e mostra como rodar localmente."

## 1:30–2:30 · Projetos
**Mostrar:** `projetos-pessoais/README.md`, repositório Plataforma-Saude-Mental, Chatbot-Whatsapp.
**Falar:** "O principal é a plataforma de saúde mental, em Go com Gin e PostgreSQL no backend e React com TypeScript no frontend. Ela é multi-tenant, usa JWT com papéis e integra pagamentos por webhook. O Chatbot de WhatsApp usa Python, Flask e Twilio. Há também o Study Hub, meus sites institucionais e a primeira versão do portfólio, na Vercel."

## 2:30–3:30 · Versionamento
**Mostrar:** página de commits, página de tags (v1.0.0), `git log --oneline --decorate` no terminal.
**Falar:** "Versionamento é registrar a evolução do código. O primeiro commit trouxe a estrutura e o site, e marquei esse ponto com a tag v1.0.0. Depois fiz melhorias em commits separados, seguindo Conventional Commits: feat, docs, style. Cada commit conta o que mudou e por quê, e permite voltar atrás se preciso."

## 3:30–4:20 · GitHub Pages
**Mostrar:** https://eduspv.github.io/PortfolioHUB/ — navegar por Sobre, Projetos, Competências e Contato; reduzir a janela para mostrar o layout móvel.
**Falar:** "Este é o site publicado no GitHub Pages, direto da branch main. Tem menu, projetos acadêmicos e pessoais com tecnologias e links, competências e contato. É responsivo e usa animações leves."

## 4:20–5:00 · LinkedIn e conclusão
**Mostrar:** perfil do LinkedIn (seção Projetos/Destaques, se já adicionado).
**Falar:** "Adicionei o projeto ao LinkedIn com link para o repositório e para o site, para que recrutadores vejam meu trabalho. O portfólio mostra não só o resultado, mas o processo. Obrigado pela atenção."
